# Employee Attrition Prediction

A machine learning project that predicts employee attrition using employee, job, and workplace information.

## Features

- Data cleaning and preprocessing
- Exploratory data analysis
- Categorical feature encoding
- Feature preparation
- Feature scaling
- Artificial Neural Network
- Model training and evaluation
- Dropout and regularization techniques

## Dataset

The dataset contains 1,470 employee records with information including:

- Age
- Job role
- Department
- Monthly income
- Job satisfaction
- Work-life balance
- Years at company
- Years in current role
- Years since last promotion
- Years with current manager
- Business travel
- Marital status

The target variable is employee attrition.

## Model

An Artificial Neural Network (ANN) is used to predict whether an employee is likely to leave the company.
