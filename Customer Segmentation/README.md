# Customer Segmentation

A machine learning project that groups customers into different segments based on their characteristics and behavior.

## Features

- Data preprocessing
- Exploratory data analysis
- Feature selection
- Customer segmentation
- Data visualization
- Cluster analysis

## Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

## Files

- `Customer Segmentation.ipynb` - Data analysis and customer segmentation

## Note

This project was created as a machine learning practice project.
