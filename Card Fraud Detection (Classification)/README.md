# Card Fraud Detection

A machine learning project that uses classification techniques to detect fraudulent card transactions.

## Features

- Data preprocessing
- Exploratory data analysis
- Feature preparation
- Classification model
- Fraud prediction
- Model evaluation

## Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

## Project Structure

- `Card Fraud Detection.ipynb` - Main analysis and model development

## Note

This project was created as a machine learning practice project.
