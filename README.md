# Machine Learning Projects

This repository contains some of my machine learning projects built while learning and working with different machine learning concepts.

The projects cover different types of problems, including regression, classification, NLP, and recommendation systems.

## Projects

### House Price Prediction

A machine learning project for predicting house prices using property-related features.

Main work includes data preprocessing, analysis, feature preparation, model training, and evaluation.

### Loan Approval Prediction

A classification project that predicts whether a loan application will be approved based on applicant information.

The project includes data preprocessing, analysis, model training, and evaluation.

### Employee Attrition Prediction

A machine learning project that predicts whether an employee is likely to leave a company based on different employee-related factors.

### E-Commerce Recommendation System

A recommendation system for an e-commerce application.

The project explores different recommendation approaches, including:

- Content-based recommendation
- Collaborative filtering
- Hybrid recommendation
- Multi-model recommendation

The project also includes a Flask-based web application for the e-commerce system.

### Spam Email Detection

A text classification project that detects whether an email is spam or ham.

The project uses:

- NLTK for text preprocessing
- Stopword removal
- Porter stemming
- CountVectorizer for feature extraction
- Random Forest for classification

The model achieved around 96.33% accuracy on the test data.
